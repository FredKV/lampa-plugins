# Мій день — планер для Android

Плани · Календар важливих справ · Фінанси (доходи/витрати) · Кухня з AI (Gemini) · Список покупок з цінами Сільпо.

## Як встановити
1. Відкрийте вкладку **Releases** репозиторію → `planer-latest` → завантажте `MyDen.apk`.
2. Відкрийте файл на телефоні, дозвольте встановлення з невідомих джерел.

APK збирається автоматично GitHub Actions (`.github/workflows/planer-apk.yml`) при кожній зміні в `planner-app/`.

## Gemini (безкоштовно)
1. Зайдіть на https://aistudio.google.com/apikey і створіть ключ.
2. У додатку: ⚙ Налаштування → API ключ → Зберегти.

Без ключа працюють вбудовані рецепти (борщ, вареники, олівʼє, сирники, карбонара, млинці).

## Структура
- `app/src/main/assets/www/` — інтерфейс (HTML/CSS/JS), можна відкрити `index.html` у браузері для перевірки.
- `app/src/main/java/.../MainActivity.java` — WebView + міст для HTTP-запитів до Gemini, відкриття посилань, теми.
- Дані зберігаються локально на телефоні.
