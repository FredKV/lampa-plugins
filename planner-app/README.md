# Танічка🦝 — особистий планер для Android

Плани · Календар (місячна сітка) · Менструальний цикл · Дні народження й подарунки · Погода · Фінанси та бюджет · Хотілки (накопичення) · Вигідні продукти для страви · Список покупок.

## Встановлення
Releases → `planer-latest` → `Tanichka.apk`. Оновлення ставиться поверх старої версії, дані зберігаються
(при першому запуску v2 дані v1 автоматично мігрують, резервна копія лишається в `planer.v1.backup.v1`).

## Архітектура
- `app/src/main/java/...` — Android-оболонка (WebView) і нативні сервіси:
  - `MainActivity` — міст `AndroidBridge`: HTTP із заголовками (без CORS-обмежень), запити Gemini (ключ додається нативно), геолокація, фото/камера, тема.
  - `Reminders`, `ReminderReceiver`, `BootReceiver` — локальні сповіщення (AlarmManager), відновлення після перезавантаження.
  - `Store` — приватне нативне сховище (ключ Gemini, розклад нагадувань).
- `app/src/main/assets/www/` — інтерфейс, по модулю на файл:
  `core.js` (сховище, міграції, роутер, фото в IndexedDB, PIN) · `finance.js` · `plans.js` (+головна) · `calendar.js` (+цикл) ·
  `birthdays.js` · `weather.js` · `wishes.js` · `prices.js` (страва → інгредієнти → магазини) · `shop.js` · `main.js` (ще, налаштування, запуск).
- Дані: `localStorage['planer.v1']`, поле `v` — версія схеми; міграції в `MIGRATIONS` (`core.js`). Фото — IndexedDB `tanichka-photos`.

## Зовнішні сервіси
| Що | Джерело | Ключ |
|---|---|---|
| Погода, пошук міст | Open-Meteo | не потрібен |
| Рецепт і список інгредієнтів | Google Gemini API | безкоштовний, вводиться в налаштуваннях (без ключа — 6 вбудованих рецептів) |
| Ціни NOVUS, METRO, Auchan, MEGAMARKET, ЕкоМаркет та ін. | відкритий пошук каталогу zakaz.ua (`stores-api.zakaz.ua`) | не потрібен |
| Ціни Сільпо | відкритий пошук каталогу сайту (`sf-ecom-api.silpo.ua`), філія обраного міста | не потрібен |
| Ціни АТБ | сторінка пошуку atbmarket.com (загальнонаціональні ціни) | не потрібен |
| VARUS | відкритого пошуку немає → «ціни недоступні» | — |

ШІ ніколи не генерує ціни: Gemini отримує лише запит на рецепт. Ціни, вага/обʼєм упаковки, наявність і посилання беруться
з каталогів магазинів; вартість рахується за повні упаковки або за мінімальним кроком зважування магазину.
Це публічні пошукові сервіси сайтів, а не офіційні партнерські API — їх формат може змінитися; тоді магазин показується як «ціни недоступні».

Ключ Gemini зберігається не у вебкоді, а в приватному нативному сховищі застосунку й додається до запиту в Java; до експорту не потрапляє.

## Тести
```
node tests/ui-test.js           # Playwright: міграції v1→v3, усі модулі, інтеграції; магазини — записані реальні відповіді (tests/fixtures)
node tests/live-prices.js борщ  # жива перевірка цін у справжніх магазинах (потрібен інтернет і curl)
```
APK збирається GitHub Actions (`.github/workflows/planer-apk.yml`); коміти з `[wip]` не оновлюють реліз.
